# Lichen Kiln

An on-device yoga and meditation teacher. Personalized sessions, breathing, sleep, and a private journal — fully offline. No account. No cloud.

**App Name:** Lichen Kiln

There is no account, no login, no cloud sync, and no remote AI. Lichen Kiln is a personal wellness learning system that teaches yoga, breathing, mindfulness, meditation, relaxation, flexibility, and steady daily routines - privately, on your device.
