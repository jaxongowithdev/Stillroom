## Review notes

Brume Lamp is not a timer wrapper. Reviewers can:

1. Complete onboarding (aim, minutes, body feel).
2. Open **Lamp** and light the session the on-device teacher chose.
3. Open **Lessons** and run **Window unknot**, or read a pose chimney card.
4. Open **Fog glass** and run **Glass of four** — the bar fills and empties.
5. Open **Pages**, write one sentence, save. Toggle Airplane Mode — the library still works.

There is no account, no login, no cloud sync, and no remote AI. A private journal — fully offline. No account. No cloud.
